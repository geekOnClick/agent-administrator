# Возможности
Этот агент предназначен для работы с файлами (счетами) формата xlsx/xls/pdf/doc/docx или простым общением с локальной моделью gemma4:e4b-8k используя провайдер Ollama.
При работе со счетами модель использует tool `process_bills` для обработки документов и подсчета итоговой суммы к оплате.
Для работы с файлами требуется указать путь к папке или конкретному файлу.

# Установка
Для запуска агента выполните
- npm install
- npm run start
- в CLI режиме выберите интересующий вас режим работы (документы или общение)

# Моды
1. talk - мод для общения с моделью в формате текстового стриминга
2. bills - Файлы обрабатываются детерминированным кодом, а не LLM:
- DocumentsService.ts (строки 282–299) читает файлы напрямую через xlsx, pdf-parse, mammoth
- Суммы извлекаются регулярными выражениями (extractAmountCents, строки 241–276)
- Модель получает только готовый результат — итоговую сумму и детализацию как текст
LLM лишь вызывает инструмент process_bills (через MCP) и формулирует ответ пользователю на основе его вывода. Сами счета в контекст модели не передаются.
3. billsWithModel - обработка счетов силами внешней модели
- PDF-файлы передаются как base64 в routerai (модель google/gemini-3.5-flash, OCR-движок mistral-ocr для сканов) вместе с промптом BILLS_WITH_MODEL_SYSTEM_PROMPT
- Модель сама находит итоговую сумму в каждом счёте и считает общий ИТОГО
- Агент сохраняет ответ модели как отчёт bills_with_model_report_<timestamp>.txt в ту же папку со счетами
